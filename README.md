# 🩺 Терапевтический симулятор

Интерактивный симулятор приёма пациента для отработки навыков клинического мышления терапевта.

## Описание

Приложение моделирует работу врача-терапевта в приёмном отделении. Пользователь проходит три этапа работы с каждым пациентом:

1. **Опрос** — задаёт вопросы пациенту, собирает анамнез
2. **Обследования** — назначает необходимые анализы и исследования
3. **Диагноз** — просматривает результаты и формулирует заключение

По итогу выставляется балл и сравнивается поставленный диагноз с правильным.

## Стек

- [Streamlit](https://streamlit.io/) — веб-интерфейс
- Python 3.10+
- JSON — формат хранения клинических кейсов

│   ├── avatars/            # SVG-аватары пациентов

## Формат клинического кейса

Каждый кейс — JSON-файл в `data/cases/` с именем `case_N.json`:

```json
{
    "id": 1,
    "last_name": "Иванов",
    "first_name": "Иван",
    "patronymic": "Иванович",
    "age": 45,
    "sex": "М",
    "history": "Жалобы пациента...",
    "img": "avatar1.svg",
    "questions": [
        { "q": "",            "a": "Здравствуйте, доктор!", "weight": -1 },
        { "q": "Где болит?",  "a": "В правом боку.",        "weight": 1.0 },
        { "q": "Есть тошнота?", "a": "Да.",                 "weight": 0.8 }
    ],
    "exams": [
        { "name": "Общий анализ крови", "type": "table", "file_name": "oac.csv" },
        { "name": "Рентгенография ОГК", "type": "image", "file_name": "xray.jpg" }
    ],
    "answer": "Острый аппендицит"
}
```

**Поле `weight` у вопросов:**
| Значение | Смысл |
|----------|-------|
| `-1` | Приветствие (показывается автоматически, не задаётся) |
| `0` | Нерелевантный вопрос (не показывается пользователю) |
| `0.1–1.0` | Полезный вопрос; чем выше — тем важнее для диагноза |

**Типы файлов обследований (`type`):**
- `image` — JPEG/PNG, отображается как картинка
- `table` — CSV, отображается как таблица

Файлы обследований размещаются в `data/media/`.

## Система оценки

Балл за опрос рассчитывается как отношение суммы весов заданных вопросов к сумме весов всех возможных вопросов (с `weight > 0`):

```
Балл = (сумма весов заданных вопросов / сумма всех весов) × 100%
```

Диагноз считается верным при точном совпадении с эталонным ответом из кейса.
